# Projeto Integrador Extensionista III

## Objetivo
Desenvolver uma solução tecnológica colaborativa baseada em software livre para fortalecer segurança comunitária, inclusão digital e acesso a serviços essenciais.

## Público-alvo
Comunidade de Ituiutaba-MG.

## Funcionalidades previstas
- Sistema de alertas
- Inclusão digital
- Comunicação comunitária
- Monitoramento colaborativo

## Tecnologias previstas
- GNU/Linux
- Software Livre
- Banco de Dados
- APIs de comunicação
